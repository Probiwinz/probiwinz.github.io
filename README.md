# Beluga Whale Links

This project is a simple static web page that collects a few
links about **Beluga whales**. It consists of an `index.html` file
with the content and a `main.css` stylesheet for a tiny bit of
styling.

## Usage

Open `index.html` in your web browser. You can double-click the file
or serve it through any static web server.

## Modifying the site

- To add or change links, edit `index.html`.
- Update styles in `main.css`.
- You can expand the page by adding more HTML or JavaScript files
  as needed.
